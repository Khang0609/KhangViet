## [09:26] Missing/Duplicate React Key in InHouseEngineering List
- **Category / Tech:** React, Next.js
- **Symptom:** `Console Error: Each child in a list should have a unique "key" prop.` in `InHouseEngineering.tsx` at `<ProductionDivisionCard key={division.id} />`.
- **Root Cause (Concept):** Relying solely on `division.id` from CMS/DB JSON data breaks React reconciliation if any record omits `id` or has duplicate `id` values.
- **Fix / Pattern:** Use a deterministic composite fallback key `` `${division.id || division.name || "division"}-${index}` `` when rendering CMS-driven arrays.
- **Case Abstract:** `apps/web/components/modules/InHouseEngineering.tsx`
