
## [23:00] Wrangler Dev Localhost Blocked by Production Auth Guard
- **Category / Tech:** Cloudflare Workers, Wrangler, Hono, Cloudflare Access
- **Symptom:** Opening `/admin` during `pnpm turbo run dev` returned `401 Unauthorized` ("Không có quyền truy cập") even on localhost.
- **Root Cause (Concept):** `apps/api/wrangler.jsonc` defines `"NODE_ENV": "production"` in `vars`, which `wrangler dev` injects locally. Checking only `NODE_ENV === "production"` caused local dev requests to enforce `Cf-Access-Jwt-Assertion`.
- **Fix / Pattern:** Allow local dev bypass only when `hostname` is `127.0.0.1`/`localhost` AND `CF_ACCESS_TEAM_DOMAIN`/`CF_ACCESS_AUD` are not configured; enforce strict fail-closed JWT verification whenever `CF_ACCESS_AUD` is set or running on a non-local host.
- **Case Abstract:** `apps/api/src/middlewares/authMiddleware.ts`
